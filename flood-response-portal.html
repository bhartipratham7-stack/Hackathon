Live flood trend

This chart combines the latest hourly rain pattern with a transparent calculated water-level proxy so people can see whether conditions are rising, stable, or easing. Flood API river discharge is used when available. [web:12][web:20]

Note: exact street-level flood depth is not universally available for every city. The portal shows live weather, nearest river discharge when available, and a clearly labeled risk proxy rather than inventing false precision. [web:12][web:20]
